# 超星快递侠 (StarCourier)

> 从超星给你「派送」课件文件的侠客 —— PPT / PDF / 视频一键批量下载，云盘文件签名直链，失败自动兜底。

![license](https://img.shields.io/badge/license-MIT-green) ![platform](https://img.shields.io/badge/platform-Tampermonkey-00485b)

## 特性

- **一键批量派送**：点击反应堆启动器弹出资源列表勾选下载，或按 `D` 键直接下载本节全部 PDF
- **云盘文件支持**：自动获取官方签名直链，普通脚本对 `cldisk` 云盘文件会无响应卡死，这里原生支持
- **多级智能兜底**：签名直链 → 接口地址 → 浏览器原生下载 → 手动下载页，层层自动切换，失败必提示原因
- **反应堆进度光环**：启动器就是进度条 —— 下载时光环实时显示百分比，不用打开任何窗口
- **完全可拖动**：启动器随便拖（靠边自动吸附、位置自动记忆），弹窗按住头部也能拖
- **还原原始文件名**：直接使用老师上传时的原始文件名（如「第1章 概述.ppt」）
- **失败单条重试**：批量派送中某个文件失败，单独重试即可，不用整批重来
- **实时下载速度**：进度旁显示 `x.x MB/s`

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 Tampermonkey 管理面板 → 点击「+」新建脚本 → 粘贴 [`Download.js`](./Download.js) 的全部内容 → `Ctrl + S` 保存
3. 打开超星课程学习页面，左侧出现发光的反应堆启动器即安装成功

## 使用

| 操作 | 效果 |
| --- | --- |
| 点击反应堆启动器 | 弹出资源列表，勾选后点「下载选中」 |
| 按住启动器 / 弹窗头部拖动 | 随意挪动位置（自动吸附屏幕边缘并记忆） |
| 按 `D` 键 | 跳过弹窗，直接下载本节全部 PDF |
| 按 `Esc` 键 | 关闭资源列表 |
| 首次下载弹权限询问 | 点「总是允许」（脚本需要访问 chaoxing.com / cldisk.com 下载文件） |

## 常见问题

**提示"可能触发了风控，建议等几分钟再试"？**
短时间频繁请求会触发超星风控，属临时限制，等几分钟后重试即可。

**下载文件名为什么是老师上传时的原名？**
快递侠通过官方跳转链获取带签名的下载地址，签名参数里携带原始文件名，直接还原。

**支持哪些页面？**
超星系课程学习页（`mycourse/studentstudy`、`mycourse/teacherstudy`）与知识点页（`nodedetailcontroller`），兼容学银在线等部署。
